## What I Do

**Benchmark & evaluation engineering — Project Dynamo (Handshake AI)**
I build and rework Harbor-format tasks that stress-test AI agents across scientific computing, machine learning, mathematics/formal reasoning, and physics simulation. Each task is engineered end-to-end: reference solution, isolated verifier, seeded randomness, and protected ground truth — designed so difficulty comes from genuine algorithmic and mathematical complexity, not ambiguity or information hiding. I work the full fork → PR → automated multi-gate review (tier1, QC gate, adversarial review, pass@k) → iterate cycle, and take on rework assignments to fix flagged tasks against reviewer findings.

**AI evaluation — Vedron.ai**
Author PhD-level evaluation problems in astrophysics and gravitational-wave physics (magnetar energy budgets, strain/braking-index derivations) used to assess frontier model reasoning.

**Science communication**
Run a Hindi-language physics/science YouTube channel producing short-form and long-form explainer content — including full production pipelines (narration scripting, Manim-animated storyboards, subtitled renders) — and write for **[Engineerspedia](https://engineerspedia.netlify.app/)**, an engineering-explainer blog aimed at making core engineering concepts accessible without the jargon.
